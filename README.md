# 🐤 估股跡 (GuGuJi) — 台股實戰操作記錄與策略驗證系統【完整使用手冊】

> 🔗 **立即開啟 Web 線上版**：[https://laogoon.github.io/GuGuJi-Web/](https://laogoon.github.io/GuGuJi-Web/)

**估股跡 (GuGuJi)** 是一套專為台股投資人設計的**實戰交易帳本、強勢股選股策略驗證、以及停損／達標／持有天數自動盯盤警示系統**。無論使用**電腦瀏覽器**或**手機瀏覽器**，登入同一組帳號即可跨裝置即時同步所有實戰紀錄。

---

## 📌 一、 快速開始：註冊、登入與手機安裝捷徑

### 1. 註冊與登入個人專屬空間
1. 點擊上方網址進入系統首頁。
2. 首次使用請切換至 **「註冊新帳號」**，輸入您習慣的**使用者帳號**與**密碼（至少 4 碼）**即可完成建立。
3. 每個帳號的持股部位、自訂策略與系統設定皆**完全獨立保存**，並於每次操作存檔時自動同步至雲端資料庫與本機快取。
4. 換手機或換電腦時，只需切回 **「帳號登入」** 輸入原帳號密碼，即可自動載入最新資料。

### 2. 手機版「加入主畫面」當作 App 使用（推薦）
- **iPhone (Safari)**：開啟網址後，點擊底部「分享」圖示 ➔ 選擇 **「加入主畫面」**。
- **Android (Chrome)**：開啟網址後，點擊右上角「⋮」選單 ➔ 選擇 **「加到主畫面」** 或 **「安裝應用程式」**。
- 加入後手機桌面即會出現「**估股跡 GuGuJi**」小雞圖示，點開即可全螢幕看盤記帳！

## 📈 二、 實戰部位看板：新增買入、分批加減碼與自動報價

### 1. 新增第一筆股票買入紀錄
點擊右上角（手機版為底部中央）的 **「＋ 新增買入」** 按鈕：
- **股票代號 / 名稱自動補齊**：內建台股 **1,988 檔上市 (TSE) / 上櫃 (OTC)** 股票清單，輸入股號（如 `2330`）或股名（如 `台積電`）即會自動帶出對應股票與市場別；若為新掛牌股票亦可直接輸入並自動加入自訂股號庫。
- **買入張數（支援整股與盤中零股）**：
  - 輸入 `1` 代表整股 1 張（1,000 股）。
  - 支援小數點輸入盤中零股（例如輸入 `0.5` 代表 500 股，`0.05` 代表 50 股），系統會自動依整股／零股低消規則精算手續費。
- **證交稅率類別**：
  - 預設為 **一般股票 (`0.3%`)**；若輸入 `00` 開頭之代號會自動切換為 **ETF (`0.1%`)**；亦可手動切換為 **現股當沖 (`0.15%`)**。
- **買入理由（複選策略 ＋ 自訂理由）**：
  - 可從下拉選單中**勾選 1 個或多個買入策略**（亦可直接在選單內點擊「＋快速新增策略」）。
  - 若有額外操作想法，可勾選 **「自訂」** 並填寫補充說明（如：`突破季線轉強`、`法說會利多`）。
- **停損 (%) ／ 達標 (%) ／ 預計持有 (工作天)**：
  - 勾選策略後，系統會自動帶入該策略建議的**停損比例**、**達標比例**與**預計持有工作天數**（並即時推算顯示預計出場到期日 `YYYY-MM-DD`）。
  - 您也可以針對單筆持股自由微調這三個數值。

### 2. 自動上網爬蟲抓價（開盤價 & 最新市價）
- 儲存持股後，系統會在背景自動查詢該檔股票於**買入當天的開盤價**以及**目前最新市價／收盤價**。
- 在看板頂部點擊 **「🔄 更新全部現價」**（或單張卡片上的重新整理圖示），即可一鍵批次刷新所有持股最新報價；亦可直接在卡片上點擊價格手動微調。

### 3. 分批加碼、分批減碼與平倉結算
- 點擊持股卡片上的 **「➕ 分批加碼」** 或 **「➖ 賣出/平倉」** 按鈕：
  - 支援多次分批買進與分批賣出。
  - 系統會自動拆分計算：**加權平均買入價**、**目前剩餘庫存張數**、**已實現淨損益（已扣除買賣雙向手續費與賣出證交稅）** 與 **未實現預估淨損益**。
  - 當剩餘庫存張數歸零時，該部位會自動歸類至 **「已平倉結算」** 分頁，完整保留歷史戰績供日後複盤。

## 🔔 三、 三大智慧盯盤警示：停損、達標、持有到期

系統會在每次登入及更新報價時，針對**尚未平倉**的持股自動檢查以下三種警示條件，並在看板頂部監控卡、個股卡片與主動彈跳視窗中提醒：

1. **🎯 達標止盈警示（紅色）**：
   - 當股價相對計算基準的漲幅 **$\ge$ 達標比例**（如 `+20%`）時觸發。
2. **⚠️ 觸發停損警示（綠色）**：
   - 當股價相對計算基準的跌幅 **$\le$ 停損比例**（如 `-10%`）時觸發。
3. **⏰ 持有到期／超期警示（琥珀金色）**：
   - 依週一至週五**工作天**計算（自動排除週六、週日，買入當日計為第 1 個工作天）。
   - 當 **已持有工作天 $\ge$ 預計持有工作天（預設 20 天）** 時立即觸發警示，且**在超過預計持有天數後只要尚未平倉，皆會持續維持警示狀態**，提醒檢視資金效率與換股時機。

## 🧩 四、 策略管理與實戰成效統計

切換至 **「策略管理與成效」** 分頁：
- **內建 8 大黃金策略**：
  1. `鳳凰涅槃` (`strat_31`)
  2. `一見鍾情` (`strat_32`)
  3. `金主推山` (`strat_33`)
  4. `奇兵破浪` (`strat_34`)
  5. `雙核驅動` (`strat_35`)
  6. `絕地反攻` (`strat_36`)
  7. `橫空出世` (`strat_37`)
  8. `波段超強` (`strat_38`)
- **新增與編輯策略**：
  - 點擊 **「＋ 新增自訂策略」** 可建立屬於自己的選股策略，自由設定專屬的**停損比例 (%)**、**達標比例 (%)**、**預計持有 (工作天)** 與組成篩選條件（您新增的自訂策略會自動排在清單最前方）。
  - 點擊任何策略卡片右上角的「編輯」圖示，皆可隨時調整該策略的停損、達標與預計持有天數。
- **實戰績效自動統計**：
  - 每張策略卡片皆會根據您的真實交易部位，自動統計該策略的 **實戰使用次數、勝率 (%)、平均漲跌幅 (%) 與累計淨損益 (元)**，協助找出最適合自己的高勝率策略。

## ⚙️ 五、 系統設定與台股稅費規則

切換至 **「系統設定」** 分頁，可自訂個人化的看盤與計算參數（點擊「儲存系統設定」後立即同步至雲端）：

1. **停損與達標的計算基準方式**：
   - **以「買入價」計算（預設）**：以您實際輸入的加權買入成交均價作為 `0%` 基準。
   - **以「買入當天開盤價」計算**：以系統自動爬取的買入當日開盤價作為基準，用於驗證策略訊號日開盤後的客觀表現。
2. **買入理由「自訂」欄位的預設值文字**：
   - 設定勾選「自訂」理由時自動帶入的預設字串。
3. **台股手續費折數與最低手續費**（點擊標題右側 **🧮 計算機圖示** 可隨時彈出完整公式說明小視窗）：
   - **券商手續費折數**：預設為 **`10`（代表不打折）**；若您的券商提供 6 折請填 `6`、2.8 折請填 `2.8`。
   - **手續費計算公式**：`成交金額 × 0.1425% × (折數 ÷ 10)`（小數點無條件捨去）。
     - **整股（1 張 = 1,000 股）**：每筆最低收 `20` 元（可依券商調整）。
     - **盤中零股（1 ~ 999 股）**：單筆未滿 `1` 元者按 `1` 元計收。
   - **證券交易稅（僅賣出時課徵）**：一般股票 `0.3%`、現股當沖 `0.15%`、一般 ETF `0.1%`。
4. **新策略預設比例與預計持有天數**：
   - 設定建立新策略或未選策略時的預設停損（預設 `-10%`）、預設達標（預設 `+20%`）與預設預計持有工作天（預設 `20` 天）。
5. **介面字體大小設定**：
   - 手機版已預設自動適度放大字體；您可依閱讀習慣隨時切換 **「標準字體」**、**「大字體 (+12%)」** 或 **「特大字體 (+25%)」**，亦可透過頂部太陽／月亮圖示一鍵切換 **深色看盤模式** 與 **淺色模式**。

## 👤 六、 個人帳號管理、報表匯出備份與刪除帳號

點擊畫面左上角「`帳號：{您的帳號}`」右側的 **「👤 人形圖示」**，即可開啟 **「個人帳號管理」** 視窗：

1. **帳號狀態與登出切換**：
   - 檢視目前登入帳號、累計部位筆數、自訂策略數量與最後雲端同步時間，並可點擊 **「登出切換帳號」**。
2. **交易報表匯出與完整資料備份**：
   - **匯出 CSV 台股實戰損益報表 (Excel 可開)**：一鍵下載包含買賣均價、策略、持有工作天、已實現與未實現淨損益的完整表格。
   - **匯出／匯入 JSON 完整備份**：可將整個帳號（包含所有系統設定值、持股明細、自訂策略與條件）打包下載為 `.json` 備份檔，或隨時匯入還原。
3. **修改登入密碼**：
   - 輸入新密碼並確認後，立即更新本機與雲端密碼。
4. **刪除個人帳號（安全確認機制）**：
   - 點擊「刪除帳號...」後，需**輸入目前登入密碼**確認，通過後系統會將該帳號於雲端與本機的所有資料永久清除（建議刪除前先點擊上方「匯出 JSON 完整備份」留存資料）。
